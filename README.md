# LCEC-IO

Industrial EtherCAT slave I/O board: STM32F405VGT6 + LAN9252, 8 digital inputs, 12 MPG selector inputs, MPG encoder, 8 pluggable relay outputs, 2 × 0–10 V analog outputs. Designed in KiCad 10 with Claude Code.
